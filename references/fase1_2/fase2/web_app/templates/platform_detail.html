Como Usar no {% if platform == 'arduino' %}Wokwi{% else %}PlatformIO{% endif %}
{% if platform == 'arduino' %}
Passos para Arduino IDE + Wokwi:
  1. Copie o código .ino acima
  2. Acesse wokwi.com
  3. Crie novo projeto ESP32
  4. Cole o código no editor
  5. Copie o JSON do diagrama
  6. Configure o circuito usando o JSON
  7. Execute a simulação
{% else %}
Passos para PlatformIO + Wokwi:
  1. Instale PlatformIO: pip install platformio
  2. Crie projeto: pio project init --board esp32dev
  3. Copie platformio.ini para a raiz do projeto
  4. Copie wokwi.toml para a raiz do projeto
  5. Adicione o código C++ em src/main.cpp
  6. Compile: pio run
  7. Simule no Wokwi: pio run --target sim
