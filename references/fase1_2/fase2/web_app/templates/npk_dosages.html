Como o Sistema Calcula
📐 Fórmula Utilizada:
Quantidade Total = Área (m²) × Dosagem (kg/m²)
📊 Exemplo Prático:
Área Exemplo:
500 m²
Cálculos:
N Nitrogênio: 500 × {{ culture_data.dosages.nitrogen.amount / 1000 }} = {{ (500 * culture_data.dosages.nitrogen.amount / 1000)|round(2) }} kg
